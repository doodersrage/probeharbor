# SmartThings (via Matter)

ProbeHarbor does **not** ship a SmartThings Cloud-to-Cloud connector.

Use the [Matterbridge plugin](https://github.com/doodersrage/thermaltrace-matter) so SmartThings can add garage temperature, humidity, leak, door, power, and motion over Matter on your LAN — the same path as Apple Home and Google Home.

- Product: [probeharbor.dev/integrations/smartthings](https://probeharbor.dev/integrations/smartthings)
- Matter install: [probeharbor.dev/integrations/matter](https://probeharbor.dev/integrations/matter)
- Positioning vs consumer pods: [probeharbor.dev/compare/govee](https://probeharbor.dev/compare/govee)
